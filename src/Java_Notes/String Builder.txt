String Builder

Object
 └── AbstractStringBuilder
      └── StringBuilder
           └── implements CharSequence, Appendable, Serializable
Package: java.lang

| Constructor                       | Purpose                              |
| --------------------------------- | ------------------------------------ |
| `StringBuilder()`                 | Empty builder, default capacity = 16 |
| `StringBuilder(int capacity)`     | Empty builder with custom capacity   |  if crosses the capacity limit then new capacity is newCapacity = (oldCapacity * 2) + 2 
| `StringBuilder(String str)`       | Initialize with string               |
| `StringBuilder(CharSequence seq)` | Initialize with sequence             |

StringBuilder NEVER throws an error when capacity is exceeded
Capacity is mentioned to avoid repeated memory allocation and copying when the final size of data is known in advance.

StringBuilder grows automatically for safety, but specifying capacity improves performance and reduces memory overhead.

indexOf() is a String method used to find the position (index) of a character or word inside a String.
✅ the index number (starting from 0) if found
❌ -1 if not found

indexOf(String, startPosition)

int start = s.indexOf("World"); // 6
int end = s.indexOf("World",start+5); //gives next world index which is 12
