Wrapper classes

Wrap the primitive data type into objects

We can use collections by object form only
To store the data in collection we have to store in object
all wrapper classes are inbuilt classes which is developed by wrapper classes
byte -> BYTE

long -> Long

Boxing -> The process of converting primitive data into the non primitive type
Autoboxing -> Automatically compiler will do boxing
Unboxing -> Non primitive to primitive
Autounboxing -> Automatically compiler will do unboxing


intValue() -> unboxing in explicit way 
Double d = 2.5;
double x = d.doubleValue();

In collections compiler will do autoboxing

ArrayList<Integer> list = new ArrayList<>();
list.add(5);   // int → Integer automatically
