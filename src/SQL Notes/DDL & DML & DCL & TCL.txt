DDL & DML & DCL & TCL

IT IS USED TO DEALS WITH THE STRUCTURE OF THE TABLE
With the help of ddl we can build,modify or destroy the structure of the table

Statements
CREATE,RENAME,ALTER,TRUNCATE,DROP

Tables cannot have same names
Name of the table

Assign datatypes for the columns
Assign Constraints [NOT MANDATORY]

RENAME:

USED TO CHANGE THE NAME OF THE OBJECT

RENAME TABLE_NAME TO NEW_TABLE_NAME;

//sql ansi
RENAME TABLE TABLE_NAME TO NEW_TABLE_NAME;


ALTER

It is used to alter the column name
alter table table_name add colmname datatype constraint;

add column
alter table customer add email_id char(20) unique;

drop column
alter table table_name drop column column_name;

to rename a column
alter table customer rename column phone_no to contact_no;

to modify a column (DATATYPE AND CONSTRAINT)
alter table customer modify email_id varchar(30);

TRUNCATE
It is used to delete all the records from table permenantly
It will delete only the records but structure of table remains same
We cannot recover truncated records

truncate table table_name;

DROP
delete the table along with the structure of the table
	
we can able to recover the drop tables using flash back.

The address after droping a table is bin address
drop table table_name;

select * from recyclebin; we will get the address of the dropped table

FLASHBACK

It is used to recover the drop or deleted tables from the bin to database

FLASHBACK TABLE TABLE_NAME TO BEFORE DROP;

PURGE
(Table should be in recycle bin then we can use this)
It is used delete the table permenantly or it is used to delete the table from a recycle bin

Note: Before dropping a table we cannot use a flashback or purge
purge table tablename;

DROP TABLE TABLENAME PURGE; //PERMENANT DELETE
PURGE RECYCLEBIN; //ENTIRE RECYCLE BIN IS PURGED

DDL Statements are Auto Commit Statements(Automatically Saved in databases)

DML
It is used to manipulate the object by performing insertion,updating and deletion.
Not saved automatically we should write commit after dml commands

Insert
To insert records in table

INSERT INTO Table_Name VALUES(v1,v2,v3,,,,,,,,vn);

INSERT INTO TABLE_NAME (COL_NAME1,COLE_NAME2) VALUES (VALUE1,VALUE2)

UPDATE
It is used to modify an existing value

UPDATE Table_Name SET Col_Name = Value where filter_condition

Delete

Used to remove a particular record from the table

delete from table_name where filter condition;


Before inserting any record we should start transaction/begin in MYSQL

TCL(Transaction control Language)

It is used to control the transaction in a database

Commit -> It is used to save all the transactions into the database;(DML commands)

commit;

Rollback -> It is used to get back the last save transaction. (REcover the deleted records)

rollback;

SavePoint -> It is used to mask the transaction and it is used with rollback.

savepoint savepoint_name;

rollback to s1; //return back to particular transaction/savepoint

DCL

It is used to control the data flow between the users.
GRANT
REVOKE

Grant - It is used to give the permission to user.

GRANT SQL STATEMENT ON TABLE_NAME TO USER_NAME;

Revoke - It is used to take back the permission from user.

REVOKE SQL STATEMENT ON TABLE_NAME FROM USER_NAME;


One user to another user - Connect or CONN (Travel from one user to another user)
You should enter username and pwd

GRANT SELECT ON EMP TO HR;//GIVING SELECT PERMISSION  GRANT SQLSTATEMENT ON TABLENAME TO USERNAME;

GRANT SELECT,INSERT,UPDATE,DELETE ON EMP TO HR; //GIVING ALL PERMISSIONS
