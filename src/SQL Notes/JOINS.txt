Cross join
In this join records from table 1 randomly merges with all the records in a table 2

In this join each row in table1 joins with all the rows in table2.
if table 1 contain x rows and table 2 contains y rows the result is x*y rows

SELECT column_list
FROM table1
CROSS JOIN table2;


No ON condition
No WHERE condition for matching

Rows produced -> Multiplication of rows
Columns will be +(added) and rows will be *(multiplies)
We cant perform any query on this join

we use this in : Generating combinations,Creating test data

Inner Join

It is used to obtain only the matching records from the table.
To fetch the matching records we need to use join conditions

join condition
table_name1.column_name = table_name2.column_name

For inner join -> join condition is mandatory

//ansi syntax
SELECT * FROM EMP INNER JOIN DEPT
ON EMP.DEPTNO = DEPT.DEPTNO;

//WQTD ALL EMP NAME AND DEPT NAME
SELECT ENAME,DNAME FROM EMP E,DEPT D WHERE E.DEPTNO = D.DEPTNO; // THIS IS ORACLE
SELECT ENAME,DNAME FROM EMP E INNER JOIN DEPT D ON E.DEPTNO = D.DEPTNO;  //THIS IS ANSI
//WE CAN WRITE MULTIPLE CONDITION ON ON OR WHERE CLAUSE
SELECT EMPNO,DNAME,LOC FROM EMP INNER JOIN DEPT ON EMP.DEPTNO = DEPT.DEPTNO AND DEPT.DEPTNO=30;

IF WE WANT TO DISPLAY ANY COMMON COULUMN IN BOTH TABLES IN JOIN THEN WE SHOULD WRITE TABLENAME.COLUMN NAME ON ON OR WHERE CLAUSE

//SAL GREATER THAN SMITH AND DNAME IS RESEARCH BY WHERE CLAUSE
 SELECT ENAME,SAL,DNAME,LOC FROM EMP INNER JOIN DEPT ON EMP.DEPTNO = DEPT.DEPTNO WHERE SAL>(SELECT SAL FROM EMP WHERE ENAME='SMITH') AND DNAME='RESEARCH';

// BY ON CLAUSE
 SELECT ENAME,SAL,DNAME,LOC FROM EMP INNER JOIN DEPT ON EMP.DEPTNO = DEPT.DEPTNO AND SAL>(SELECT SAL FROM EMP WHERE ENAME='SMITH') AND DNAME='RESEARCH';

Natural Join
It has two behaviours
if there is relationship(Common column) between the tables it behaves like inner join
if there is no relationships(NO Common Column) between the tables it behaves like Cross join

For Natural join we dont have any oracle syntax we have only ANSI syntax
SYNTAX

SELECT */DISTINCT COLNAME/EXPRESSION FROM TABLENAME1 NATURAL JOIN TABLENAME2

All inner join queries is possible for a natural join

SELECT EMPNO,DNAME,LOC FROM EMP natural JOIN DEPT AND DEPTNO=30; //here no common column so we can directly describe the coln name

Outer Join
This join fetches unmatching records from the table

Left Outer join

It is used to fetch the unmatching records from the left table along with matching records.

Right Outer join

It is used to fetch the unmatching records from the right table along with matching records.

Full Outer join

It is used to fetch the unmatching records from both the table along with matching records.


Syntax
//LEFT outer join in oracle
SELECT * FROM EMP,DEPT WHERE EMP.DEPTNO = DEPT.DEPTNO (+);

//RIGHT outer join in oracle
SELECT * FROM EMP,DEPT WHERE EMP.DEPTNO(+) = DEPT.DEPTNO;

//FULL OUTER JOIN
//here there is no oracle syntax so we use ansi syntax
SELECT * from emp full outer join dept on emp.deptno = dept.deptno;


SELF JOIN
Joining the table by itself is known as self join or joining the same to table
Why to join the table itself?
Data to be selected as present in the same table but in different records
Alias name is mandatory
SELF JOIN is used when a table has a relationship with itself, such as employee–manager hierarchy.

SELECT COL_NAME FROM TABLE_NAME1 T1, TABLE_NAME2 T2 WHERE T1.COL_NAME=T2.COL_NAME;
SELECT * FROM EMP E1,EMP E2 WHERE E1.MGR = E2.EMPNO;

select E1.ENAME,E2.ENAME AS MANAGER FROM EMP E1,EMP E2  WHERE E1.MGR = E2.EMPNO AND E1.ENAME='SMITH';

SELECT E1.ENAME,E1.HIREDATE,E2.ENAME AS MGR_NAME ,E2.HIREDATE AS MANAGER_HIREDATE FROM EMP E1 JOIN EMP E2 ON E1.MGR= E2.EMPNO WHERE E1.HIREDATE<E2.HIREDATE;
